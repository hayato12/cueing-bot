# キュー打ち理論（v0.3）

DJ用の曲にキューポイント（メモリーキュー／ホットキュー）を打つためのルールと、そのキューを使った曲のつなぎ方をまとめたもの。
要件定義の入力資料として使う。

- 【確定】：本人に確認済み
- 【解釈】：整理する側の解釈。要件定義の段階で再確認すること
- 【未確定】：まだ決まっていない

---

## 1. 前提（仮説）

- オーソドックスな曲では、イントロ・Aメロ・Bメロ・サビ・アウトロなどの各パートが、決まった小節数でできていることが多い。
  - BPM 120以下：各パートは **8小節** 単位
  - BPM 120超え：各パートは **16小節** 単位
- BPM 120前後の曲は、実際の曲を聴いて8小節か16小節かを決める。決められない場合は **BPM 120以下として扱う**。
- 曲同士のBPM合わせ（ビートマッチ）は、この資料の対象外とする。【解釈】

## 2. 用語と記号

| 用語 | 定義 |
|---|---|
| 小節番号 | 曲の最初の小節を **1小節目**、小節の最初の拍を **1拍目** と数える |
| キューの位置 | どのキューも、小節の1拍目に打つ |
| L（基本単位） | BPM 120以下なら **4小節**、120超えなら **8小節** |
| 2L | フレーズの単位。BPM 120以下なら8小節、120超えなら16小節 |
| メモリーキュー | 位置の目印。**1曲につき10個まで** |
| ホットキュー | A〜Hの8つ。**Hはアウトロ専用**、**A〜Gは2番以降の始まり** に使う |
| n番 | 曲の繰り返し（2番、3番…）。目印にするのは、その番の **Aメロの頭** |
| イントロの終わり | 次のパート（ふつうはAメロ）の頭の拍。Aメロの頭と同じ位置 |
| 抜け（ブレイク） | 曲の途中で、**急にキックかメロディがなくなる**、または **音量が下がる** 部分 |
| 長い（アウトロ・抜け） | **L小節以上**。BPM 120以下なら4小節以上、120超えなら8小節以上 |

BPM 120超えの曲では、すべての小節数を倍にする。ただし小節番号の数え方は変わらない（1小節目は1小節目のまま）。

## 3. キューの打ち方

### 3.1 イントロ（メモリーキュー）

| イントロの長さ | 打つ位置 |
|---|---|
| L以下 | イントロの頭とイントロの終わり |
| Lより長く、2Lより短い（L＋1〜L−1小節） | Lのかたまりと端数のかたまりの区切りごと。順番はどちらが先でもよい。重なった区切りは1つにする |
| 2L以上（Lの倍数） | イントロの終わりと、そこから L・2L・3L・4L 小節さかのぼった位置 |
| 2L以上（Lの倍数でない） | イントロをかたまりに分け（2+4+4 なのか 4+4+2 なのか、など）、**区切りごとに** 打つ。イントロの頭も含む |

- 共通ルール：イントロの終わりから **4L小節より前にはさかのぼらない**。イントロがそれより長いときは、イントロの頭には打たない。

例（BPM 120以下、L＝4）

| イントロ | 打つ小節（すべて1拍目） |
|---|---|
| 4小節 | 1, 5 |
| 4+2小節 | 1, 5, 7 |
| 2+4小節 | 1, 3, 7 |
| 8小節 | 1, 5, 9 |
| 2+4+4小節 | 1, 3, 7, 11 |
| 4+4+2小節 | 1, 5, 9, 11 |
| 16小節 | 1, 5, 9, 13, 17 |
| 20小節 | 5, 9, 13, 17, 21（1小節目には打たない） |

### 3.2 2番以降の始まり（ホットキュー A〜G）

- 2番以降の各番について、**Aメロの頭の2L小節前** にホットキューを打つ。
- 割り当ては前から順に、2番がA、3番がB、…とする。

### 3.3 アウトロ

- アウトロの頭に **ホットキューH** を打つ。
- アウトロが長いときは、Hから **L小節ごと** にメモリーキューを打つ。

### 3.4 抜け（メモリーキュー）

- 抜けの始まりと終わりにメモリーキューを打つ。
- 抜けが長いときは、始まりから **L小節ごと** に打ち、終わりにも打つ。

### 3.5 重なりと数の上限

1. ホットキューとメモリーキューが同じ位置に重なったら、**ホットキューを残し**、メモリーキューは消す。
2. メモリーキュー同士が重なったら、1つにする。
3. メモリーキューが10個を超えたら、次の優先順位で上から残す。
   1. Aメロの頭（＝イントロの終わり）
   2. Aメロの頭の2L小節前
   3. イントロのそれ以外のキュー
   4. 抜け
   5. アウトロ

   同じ順位の中では、Aメロの頭に近いもの、曲の前の方にあるものを優先する。【解釈】

## 4. つなぎ方（キューを打つ目的）

### パターンA：前の曲のホットキュー（A〜G）からつなぐ

1. 前の曲がホットキューの位置（n番のAメロの2L小節前）に来る。
2. 次の曲を、**Aメロの頭の2L小節前のメモリーキュー** から再生し始める。
3. 次の曲の音量を少しずつ上げていく。
4. 次の曲がAメロの頭に来たら、前の曲の音量を切る。これでつなぎ終わり。
   - 音量を切るのは、次の曲のAメロの頭の1拍目。前の曲も、ちょうどホットキューから2L小節進んだ位置にいる。

### パターンB：前の曲のアウトロ（H）からつなぐ

1. 前の曲がHに来たら、次の曲を再生し始める。
2. 前の曲の音量は、最初から最大のままのことが多い。
3. **次の曲のAメロが始まる直前** に、前の曲の音量を切る。
4. 次の曲がイントロを終える前にアウトロが終わりそうなときは、その場でループなどを使ってつなぐ。キューの打ち方では、ここは気にしなくてよい。

### 必要なキュー

つなぎに必ず使うのは、次の4つ。

- 次の曲：**Aメロの頭**、**Aメロの頭の2L小節前**
- 前の曲：**2番以降のホットキュー（A〜G）**、**アウトロの頭（H）**

### 次の曲のイントロが2Lより短い場合

Aメロの頭の2L小節前が存在しないときは、**曲の頭（またはイントロのビートが始まる位置）** から再生し始める。

## 5. オーソドックスでない曲の扱い【未確定：提案】

パートの長さが不規則、変拍子、BPMが途中で変わる、といった曲向けの提案。

1. **必ず打つキュー**：Aメロの頭、その2L小節前、2番以降のホットキュー、アウトロのH。これがあればつなぎは成り立つ。
2. **それ以外のキュー**：小節のかたまりがはっきり分かる場合だけ、ルールどおりに打つ。
3. **「要確認」の印**：判断に自信がない曲には印を付け、必ず打つキューだけを置き、最終的な判断は人に任せる。

## 6. 未確定事項
